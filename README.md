# 🐢 乌龟开车 — 避障拾金币

微信点开即玩的网页小游戏（H5，单文件，无需安装）。

## 怎么玩
- 乌龟驾驶小车沿三条车道前进，躲避路障/石头，拾取金币。
- 行驶里程以“公里”计分，跑得越远速度越快、障碍物越多。
- 撞车后显示最终公里数、金币数、历史最高分（自动保存在浏览器本地）。

## 操作
- 键盘：← → 或 A / D 换车道；空格/回车 开始或重新开始
- 触控：点击屏幕左半边向左换道，右半边向右换道（适配手机）

## 本地试玩
直接用浏览器打开 `index.html` 即可，无需联网。

## 在微信里分享（点开即玩）
微信不能直接打开本地文件，需要把游戏部署到公网，分享 HTTPS 链接：

1. 在 GitHub（或 Gitee / Vercel / Netlify）新建公开仓库，上传 `index.html`、`og-image.svg`、`README.md`。
2. 开启 Pages 服务（GitHub：Settings → Pages → Branch: main / 文件夹: root）。
3. 得到类似 `https://<用户名>.github.io/<仓库名>/` 的公网链接。
4. 把链接发到微信对话，对方点击即在微信内置浏览器打开；如提示风险，可点右上角“在浏览器中打开”。

> 提示：部署后请把 `index.html` 里 `og:url` 的占位 `REPLACE_WITH_YOUR_LINK` 改成实际链接，微信分享卡片会更准确。

## 文件说明
- `index.html` — 游戏主文件（HTML + CSS + JS 合一）
- `og-image.svg` — 微信分享预览图（1200×630）
- `README.md` — 本说明
